SUPER ADMIN ARCHITECTURE
==================================================

Create a separate PLATFORM ADMINISTRATION layer.

The Super Admin manages the entire Clinic OS platform.

The Super Admin must NOT belong to a normal clinic tenant.

Architecture:

Platform
 ├── Super Admin
 ├── Platform Admin
 ├── Support Admin
 ├── Billing Admin
 ├── Developer
 └── Security Admin

Tenant
 ├── Clinic Owner
 ├── Doctor
 ├── Nurse
 ├── Receptionist
 ├── Accountant
 └── Staff

Implement strict separation between Platform users and Tenant users.
